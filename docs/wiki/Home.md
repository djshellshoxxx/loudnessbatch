# LoudnessBatch Wiki

LoudnessBatch (Circuit Drift Labs) batch-analyses mixes and reference tracks in the browser and compares
loudness, peak, RMS, dynamics and stereo behaviour. Static site on GitHub Pages; audio is decoded and
analysed locally.
