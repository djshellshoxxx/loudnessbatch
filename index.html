Measurement notes

ITU-R BS.1770-5 defines 400 ms loudness gating blocks with 75% overlap, an absolute gate at −70 LKFS/LUFS and a relative gate 10 LU below the absolute-gated result. LoudnessBatch uses those rules for browser integrated loudness. EBU R 128 uses −23 LUFS as its programme target; this tool does not treat one loudness target as universally correct for music.

Estimated true peak uses browser-side interpolation in this V1 and is deliberately labeled as an estimate rather than a compliant dBTP meter.
