# testing.md: Tests, Tolerances, QA

## 1. Unit tests (lb-core, `cargo test`)

### 1.1 Filters and DSP
- K-weighting coefficients at 48 kHz match engine.md 4.1 to 1e-9.
- K-weighting magnitude at 1 kHz (any fs from 44.1k to 192k) within 0.01 dB of the 48 kHz value.
- Polyphase FIR phases each sum to 1.0 (±1e-6).
- Percentile function matches numpy `percentile(method='linear')` on 10 random arrays.

### 1.2 Loudness (synthetic, generated in-test, no files)
| Signal | Expected |
|--------|----------|
| Stereo 1 kHz sine, peak -23 dBFS each channel, 20 s, 48 kHz | Integrated -23.0 ±0.1 LUFS |
| Same at 44.1 kHz and 96 kHz | -23.0 ±0.1 |
| Mono 1 kHz sine, peak -23 dBFS | -26.0 ±0.1 (strict); -23.0 ±0.1 with `mono_as_dual_mono` |
| Digital silence 10 s | Integrated -inf, LRA n/a, no panic |
| 1 s file | Integrated valid, Short-term max n/a |
| 20 s at -36 dBFS then 20 s at -23 dBFS (stereo sine) | Integrated within 0.1 of the value computed by a reference implementation (pyloudnorm) in `gen-fixtures.py`, stored in fixture JSON |

### 1.3 True peak / level
- Full-scale 1 kHz sine 48 kHz: sample peak 0.00 dBFS, true peak 0.0 ±0.1 dBTP.
- Sine at fs/4 with 45 degree phase offset (samples land at ±0.707): sample peak -3.01 dBFS, true peak 0.0 ±0.2 dBTP.
- Sine at -20 dBFS peak: RMS -23.01 ±0.01 dBFS, crest 3.01 ±0.01 dB.
- Clip events: synthetic buffer with 4 runs of 3+ samples at 1.0 and two runs of 2 samples: count = 4.
- DC: 0.01 constant added = 1.0%.

### 1.4 Spectrum / stereo
- Pink noise 30 s: tilt 0.0 ±0.3 dB/oct. White noise: +3.0 ±0.3.
- 1 kHz sine: > 99% of band power in the Mid band.
- L = R: correlation 1.0, width -inf, `monoInStereo` true.
- L = -R: correlation -1.0, `polarityInverted` true.
- Independent white noise L/R, 10 s: |correlation| < 0.02, width 0.0 ±0.2 dB.

## 2. Standard test vectors (`tests/vectors`, fetched by `scripts/fetch-test-vectors.*`)
- **EBU Tech 3341** loudness test set (minimum and extended). Integrated cases expect -23.0 LUFS ±0.1 LU (cases with other stated targets: use the value in the EBU document). True-peak cases: within +0.2 / -0.4 dB of the stated value.
- **EBU Tech 3342** LRA cases 1 to 6: expected 10, 5, 20, 15, 5, 15 LU, ±1 LU.
- The fetch script downloads from EBU's site; if the URL changes, it prints instructions to download manually. Expected values are entered in `tests/vectors/expected.json` straight from the EBU PDFs (Phase 1 task: transcribe and double-check).
- Tests are skipped (not failed) when vectors aren't present, except in CI where the workflow fetches them.

## 3. Cross-checks (optional local, `scripts/crosscheck.py`)
On any folder of real songs: compare lb-cli against ffmpeg `ebur128=peak=true` and pyloudnorm. Integrated within ±0.1 LU, true peak ±0.2 dB, LRA ±0.5 LU. Prints a table of mismatches.

## 4. WASM / native parity
`crates/lb-wasm/tests/parity.rs` (wasm-bindgen-test, headless Chrome in CI): analyze 5 fixtures in WASM, compare every scalar to native results within 1e-6 relative (float ops may differ slightly with SIMD; anything bigger is a bug).

## 5. UI tests
- **Vitest:** store slices, match gain math, monitor matrix coefficients, CSV writer escaping, schema migrations, verdict rendering.
- **Playwright** (web build, Chromium): empty state renders; drop 3 fixtures (as mix + 2 refs); results appear; Overview verdict chips present; Tonal chart renders; Batch view filter "Problems only" shows the transcoded fixture; export CSV downloads and parses; reload page and session restores from IndexedDB.
- Desktop smoke (manual for v1): install, drop folder, play, A/B, export.

## 6. Performance tests
`cargo bench` (criterion) on a 4 min stereo 44.1 kHz WAV fixture (generated): native < 1.0 s. Playwright timing test in CI for WASM: < 2.5 s per worker (log, warn only, CI machines vary).

## 7. Manual QA checklist (before each release)
- [ ] All formats from spec.md 4.1 open in Chrome, Firefox, Safari (web) and desktop.
- [ ] A/B: no click on switch in both position modes, matched level by ear and by output meter (within 0.1 dB on a static sine pair).
- [ ] Monitor modes and band solo audibly correct (Side on a mono file = silence).
- [ ] Safety clipper lamp lights when Match to target boosts a loud track.
- [ ] Output device switch works (Chromium/desktop).
- [ ] 500-file folder in Batch view stays responsive (scroll, sort, filter).
- [ ] Offline: load web app once, go offline, reload, analyze a file.
- [ ] Session save/reopen with files moved: relink works.
- [ ] `.lbref` export/import round trip; stats show without audio.
- [ ] Debug report zip contains no paths unless ticked, never audio.
- [ ] Easter egg works and respects reduced motion.
- [ ] Light and dark themes, UI scale 80% and 150%, 700 px wide window.
